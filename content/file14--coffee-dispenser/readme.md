# Coffee Dispenser Project

## Summary

Service robotics project in which a **UR3e** robot arm moves coffee cups from a fixed point to a cup holder hole detected with an RGBD camera. The project combines manipulation, perception and a web interface for user interaction.

## What I did

- Integrated MoveIt2 for arm motion planning.
- Implemented object detection with an RGBD camera.
- Built a web interface to monitor and interact with the robot.
- Validated the system both in simulation and with the real robot.

## Technologies

- ROS2
- MoveIt2
- UR3e manipulator
- RGBD camera
- YOLOv5 for perception
- Web interface
