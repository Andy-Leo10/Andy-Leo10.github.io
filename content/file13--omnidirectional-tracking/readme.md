# Omnidirectional Tracking Trajectory

## Summary

Closed-loop trajectory tracking controller for an omnidirectional **MPO-500** robot from Neobotix, simulated in Gazebo. The robot follows a desired trajectory using nonlinear control theory.

## What I did

- Implemented a trajectory tracking controller in Python for an omnidirectional robot.
- Used nonlinear control theory to follow desired paths inside a simulated apartment.
- Validated the controller in Gazebo Classic.
- Applied the same control foundations to the trajectory-following subsystem of the **Escalerini** stair-climbing robot, published at C3 2025.

## Technologies

- ROS1
- Gazebo Classic
- Python
- Nonlinear control theory
- Neobotix MPO-500
