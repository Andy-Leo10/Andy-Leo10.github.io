# Restaurant 3.0 & Host

## Summary

Deployment of service robots in restaurant and retail environments. The project involved configuring and integrating robots to perform waiter and host tasks, improving customer service and operational efficiency in hospitality settings.

## What I did

- Configured **LuckiBot Pro** robots for waiter tasks such as delivering orders and returning dishes.
- Deployed **Nova** and **Mini** robots for host tasks, including greeting and guiding customers.
- Supported on-site integration and user training.

## Technologies

- Service robotics platforms (LuckiBot Pro, Nova, Mini)
- Kotlin

This was a private project developed at Zox Robotics LATAM. Detailed implementation files are confidential.
