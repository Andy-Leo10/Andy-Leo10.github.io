# Fabric Inspector

## Summary

Automation of visual fabric inspection for a textile manufacturing process using computer vision, a linear camera and a convolutional neural network. The system detects defects, records them and physically marks the fabric roll for later review.

## What I did

- Led the team that automated the visual inspection process of fabrics.
- Programmed the first Omron linear camera in Latin America for 2D image acquisition.
- Developed a software interface for operators to register production data.
- Trained a CNN to detect 5 types of fabric defects with over 95% accuracy.
- Integrated PLC and PC to control the machine, record defects and mark the fabric physically.

## Technologies

- Omron linear camera
- Convolutional Neural Networks (CNN)
- PLC (Programmable Logic Controller)
- Python
- Computer vision

## Results

The AI model learned to detect 5 types of fabric defects with greater than 95% accuracy.
