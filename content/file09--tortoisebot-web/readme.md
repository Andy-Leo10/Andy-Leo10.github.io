# Tortoisebot Webapp

## Summary

Web application to control a **Tortoisebot** robot in a simulated environment. The interface provides real-time camera feed, a map of the environment, joystick-like controls and waypoint navigation, connecting to the ROS backend through rosbridge.

## What I did

- Built a web frontend for teleoperation and monitoring.
- Integrated video streaming from the robot camera.
- Displayed the robot map and allowed users to send waypoints.
- Connected the web interface to the ROS2 stack via rosbridge.

## Technologies

- ROS2
- Web development (HTML/JS/Python backend)
- rosbridge
- Gazebo simulation
